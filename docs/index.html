RackAttack Editor

Séquenceur, éditeur, bibliothèque et simulateur pour le Waldorf RackAttack. Plug-in AU et VST3, et appli, pour Mac.

Télécharger pour Mac

Toujours la dernière version · Mac Apple Silicon et Intel, macOS 11 ou plus récent · toutes les versions

Installer

  1. Ouvre RackAttack-Editor-mac.dmg.
  2. Glisse chaque élément sur le dossier à côté de lui : le .component sur Components (AU), le .vst3 sur VST3, l'appli sur Applications. macOS demande ton mot de passe.
  3. Ouvre le Terminal (⌘ + Espace, tape « Terminal », Entrée), colle cette commande, Entrée, puis ton mot de passe (rien ne s'affiche quand tu le tapes, c'est normal). Elle débloque le plug-in et l'appli et vérifie que l'AU marche : 
    sudo xattr -dr com.apple.quarantine "/Library/Audio/Plug-Ins/Components/RackAttack Editor.component" "/Library/Audio/Plug-Ins/VST3/RackAttack Editor.vst3" "/Applications/RackAttack Editor.app"; killall -9 AudioComponentRegistrar 2>/dev/null; auval -v aumu Ratk Dimg | tail -1
    La dernière ligne doit dire AU VALIDATION SUCCEEDED.
  4. Dans ton logiciel (Live, Logic…), relance-le ou rescanne les plug-ins : RackAttack Editor se trouve dans les instruments.

Brancher le RackAttack

Relie le MIDI OUT du RackAttack à l'entrée de ton interface MIDI, et son MIDI IN à la sortie. À la première ouverture, l'appli te guide en trois écrans : les ports MIDI, deux réglages sur la machine (Global/Utility : Ctl. send = SysEx, receive = On, Rx PrgChg = On), puis elle trouve le RackAttack toute seule.
L'appli ne sauvegarde jamais rien dans la mémoire du RackAttack. Pour garder un changement : Shift + Store sur la machine. Pour l'annuler : Shift + Recall.

Sans machine : le simulateur

Pas de RackAttack sous la main ? Outils → Mode simulation (ou le bouton du branchement guidé) : le plug-in joue un RackAttack en logiciel, par sa sortie audio.
Pour qu'il sonne comme une vraie machine : quelqu'un qui a le RackAttack lance Outils → Mesurer mon RackAttack… (sorties Out 1/2 sur la carte son, environ 5 minutes, le plug-in guide tout), puis t'envoie le fichier .ramesure. Tu le charges avec Outils → Charger des mesures…

Mises à jour

Inutile de revenir ici : quand une nouvelle version sort, un bouton Mise à jour apparaît en haut du plug-in. Un clic l'installe (macOS demande ton mot de passe), puis tu relances ton logiciel.
