RackAttack Editor

Éditeur et bibliothèque pour le Waldorf RackAttack. Plug-in AU et VST3, et appli, pour Mac.

Télécharger pour Mac

Toujours la dernière version · Mac Apple Silicon et Intel, macOS 11 ou plus récent · toutes les versions

Installer

  1. Ouvre RackAttack-Editor-mac.dmg.
  2. Glisse chaque élément sur le dossier à côté de lui : le .component sur Components (AU), le .vst3 sur VST3, l'appli sur Applications. macOS demande ton mot de passe.
  3. Premier lancement de l'appli : clic droit → Ouvrir. Si macOS refuse : Réglages Système → Confidentialité et sécurité → Ouvrir quand même.
  4. Dans ton logiciel (Live, Logic…), relance-le ou rescanne les plug-ins : RackAttack Editor se trouve dans les instruments.

Brancher le RackAttack

Relie le MIDI OUT du RackAttack à l'entrée de ton interface MIDI, et son MIDI IN à la sortie. À la première ouverture, l'appli te guide en trois écrans : les ports MIDI, deux réglages sur la machine (Global/Utility : Ctl. send = SysEx, receive = On, Rx PrgChg = On), puis elle trouve le RackAttack toute seule.
L'appli ne sauvegarde jamais rien dans la mémoire du RackAttack. Pour garder un changement : Shift + Store sur la machine. Pour l'annuler : Shift + Recall.

Mises à jour

Inutile de revenir ici : quand une nouvelle version sort, un bouton Mise à jour apparaît en haut du plug-in. Un clic l'installe (macOS demande ton mot de passe), puis tu relances ton logiciel.
