**RackAttack Editor 0.5.8** : les fichiers de Waldorf, les patterns internes, et le morph change de tête.

- **Importer (Waldorf)…** dans la Bibliothèque : les sons d'usine, les kits bonus et les patterns que Waldorf distribue (`.mid`, `.syx`, ou le `.zip` tel quel, même avec des zips dedans) vont dans le groupe **Usine**, un dossier par jeu. Les mises à jour du système sont laissées de côté. Ces fichiers restent sur ton ordinateur.
- **Les patterns internes** (le Pattern Play de la machine) sont lus : un kit d'usine part vers la machine avec ses patterns, et ses patterns passent dans le séquenceur (clic droit sur le kit, ou OPTIONS du séquenceur). Dans l'autre sens, OPTIONS › « Toute la séquence → patterns internes » les envoie à la machine (à tester sur ta machine).
- **Comparer au simulateur** (*Outils*) : chaque son du kit en cours est joué sur la machine puis dans le simulateur ; tu vois ce qui diffère le plus (volume, hauteur, longueur, brillance), et les enregistrements sont gardés dans un fichier `.racompare` pour régler le simulateur.
- **Le cœur et le crâne** remplacent A et B sur le fader Morph, dans les menus et les messages.

Pour garder un kit sur la machine, toujours **Shift + Store**.
